Gourt's Gearing: Pre-Raid BiS for Every Class

Pick your class, spec and gear set. Every item is listed easiest first with step-by-step directions, and you tick items off as you get them. Ticks are saved in this browser and shared between sets. Gear lists come from Wowhead's WoW: Forever BiS guides.

1. Run dungeons every day

Every level 55+ dungeon boss drops 1 Tarnished Undermine Real the first time you kill it each day. Pix Xizzix in Booty Bay sells strong belts, cloaks, rings and trinkets for every class for Reals.

2. Use "Where it drops"

Switch to the Where it drops tab to see every item for your spec grouped by dungeon, quest chain, vendor or craft, so one run can cover several items.

3. Tier 0.5 for everyone

Deliana (Ironforge) / Mokvar (Orgrimmar) swap your Tier 0 pieces for Tier 0.5 at 3 points in the chain: gloves + belt (step 1), boots + legs + shoulders (step 10), helm + chest (last step). Bracers are sold by them for gold.

4. Get the addon

The Gourt's Gearing addon has the same lists in game: a character-sheet view, an arrow to dungeons and vendors, and set tags on item tooltips. Download the addon, unzip it into _forever_/Interface/AddOns/ and restart the game.

Sources: ForeverDB, Wowhead (Forever), Polestar's Mount Hyjal route and WoW: Forever guide sites, checked 20 November 2026 (client build 1.60.1). Forever is still being patched, so drop rates, prices and Real costs can change. Steps marked "from original Classic" haven't been confirmed for Forever yet.

Enchants (Crusader, +100 HP, etc.) are not covered.
